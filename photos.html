Photography

The product is the photo. On d8a.pro, every feature is a real app.d8a.pro screenshot in a color frame, with window chrome. That is the D8A image system.

How a D8A image is built

  1. A real product screenshot (strategy, specs, architecture, board).
  2. Window chrome: red / yellow / sky dots + a Geist Mono URL such as app.d8a.pro / spec → code.
  3. A color frame (red / yellow / sky-deep hard-stop gradient). One frame per image.
  4. Soft elevation: 0 8px 30px rgba(0,0,0,.18).

Treatment rules

  • Real UI only. Screenshots from app.d8a.pro. Do not mock imaginary interfaces or photoshop fake data that implies a customer.
  • Always chrome the mock. Red, yellow, sky dots, then a mono URL. That chrome is brand, not OS decoration.
  • One frame per surface. Do not stack four different frames on one slide.
  • No stock clichés. No handshakes, no people pointing at screens, no “diverse team laughing in a glass meeting room,” no blue glowing globes.
  • No Instagram filters, no vintage grade, no purple color-grade.
  • Crop tight. The product is the hero. Negative space is canvas, not a stock desk.

Do / Don’t

Do
Real product screenshots in a color frame, with window chrome and a mono URL
Don’t
Generic stock of “data” — glowing globes, matrix rain, fake dashboards, dark server-room clichés
